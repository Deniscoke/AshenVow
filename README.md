# ASHEN VOW

*What the ash remembers.*

A dark-fantasy, story-driven pixel-art action RPG with semi-open exploration. You are Ser Emeric Brand, the knight
who lit the fire that ended a kingdom — and who cannot stay dead. Walk a broken land, learn what really happened on
the night of the Kindling, and decide what redemption can mean when nothing you did can be undone.

Everything — art, music, sound, fonts — is generated by code at runtime. No external assets, no dependencies.

## Run it

Requires Node.js 18+ (only for the tiny local web server; the game itself is plain browser JavaScript).

```bash
npm start
```

Then open **http://localhost:8080** in a modern browser (Chrome, Edge, Firefox). `node server.js 8080` does the same.
Click or press a key on the title screen to start the sound.

## Controls

| action | keyboard | gamepad |
|---|---|---|
| Move | WASD / arrow keys | left stick / D-pad |
| Attack (3-hit combo) | J / Z / left click | X |
| Roll (invulnerable) | Space / K | B |
| Interact / talk / read | E / Enter | A |
| Heal (tallow candle) | R | Y |
| Kindle (curse power, when the Cinder is full) | Q | RB / LB |
| Inventory (relics, items, names) | Tab / I | Select |
| Pause (journal, settings, quit) | Esc / P | Start |

Menus: arrows to move, Enter/E/Space to confirm, Esc/Backspace to go back.

## How it plays

- **Shrines** (candle altars) heal you, refill tallow, save the game, respawn enemies, and let you travel between lit
  shrines.
- **Death** is part of the story: you return to the last shrine. Something is taken each time.
- **Kindle** doubles your strength for a few seconds. It is not free, and the game remembers.
- Choices are tracked silently. There is no morality meter. Five endings, one of them hidden.
- Save data lives in your browser (localStorage). *Continue* resumes from your last shrine or doorway.

A first playthrough takes roughly an hour; completionists will spend longer.

## What's in it

- **5 regions, 28 hand-built maps:** Saint Wendel's Rest (the hub), the Hushwood, Lenten Mere and its drowned
  abbey, the Greyharrow battlefield and ossuary, and Hallowhearth (the Upper City, the Wickward, the Pyre).
  Hidden rooms behind cracked walls, secret caves, shortcuts, and 8 shrines you can travel between.
- **5 bosses:** the Unnamed Procession, the Old Hart Aubrenn, Hollin Who Rang the Flood, Ser Odo Varr, and
  What the Ash Remembers. **13 enemy types**, from ashen pilgrims to drowned bell-monks to the passive burned dead.
- **A main story in five chapters and 8 side stories**, with about 2,500 lines of dialogue, 36 characters, 12 names
  to find and 9 relics.
- **5 endings**, one of them hidden. Which ones you can reach depends on choices the game tracks silently.

## Project layout

```
index.html            entry page; src/files.js loads every script in order
server.js             zero-dependency static server
src/engine/           core loop, rendering, lighting, input, audio synthesis, dialogue, UI, save, combat
src/art/              pixel art authored as code (sprites, tiles, props, portraits, icons, UI, fonts)
src/creatures/        enemies and bosses (art + behaviour)
src/data/             items, dialogue, quests, endings, and the five regions' maps & stories
docs/                 story bible, data/art API, cross-builder contracts, creature API
tools/                check.js (data validation), sim.js (headless gameplay simulation), preview.js (art → PNG)
```

## Technical notes

- Plain JavaScript classic scripts on a single 384×216 canvas, integer-scaled with `image-rendering: pixelated`.
- All sprites are defined as palette-indexed rows or procedural drawing on a pixel grid, baked to canvases at boot.
- Tile maps are ASCII rows; walls auto-shade faces vs tops; lighting is a half-resolution darkness buffer with
  radial light "holes" plus an additive glow pass. Weather (ash, rain, fog, embers) is particle-driven.
- Music and sound are synthesized with the Web Audio API (drones, bells, generative melodies, noise-based SFX).
- Dialogue is data-driven: nodes, choices, branch conditions (a small expression language) and actions.
- `npm test` runs the whole suite:
  - `tools/check.js` validates every map, dialogue, item, flag and sprite reference, and checks that every place can
    be reached.
  - `tools/audio_smoke.js` drives the synthesizer through a mock Web Audio graph.
  - `tools/sim.js all` runs the real engine headlessly. It fights every enemy and boss, loads every map and talks to
    everyone on it, fuzzes every dialogue under random world states, and walks the story from the crypt to all five
    endings. It also checks that no choice can block the main path.
- Append `?debug` to the URL for an overlay (F2 god mode, F3 hitboxes) and `AV.debug.*` console helpers
  (e.g. `AV.debug.play('village')`, `AV.debug.tp('upper_city')`, `AV.debug.give('hart_stone')`).
